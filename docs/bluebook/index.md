# WorkBuddy 实战蓝皮书

这里是一套面向新手、任务实践者与团队负责人的 WorkBuddy 学习路线。你不必从头背功能：先找到当前最接近的工作问题，完成一项真实任务，再沿着使用手册、实战案例、进阶系统和岗位落地逐步深入。

## 四篇内容

### 第一篇 · 使用手册：先把 WorkBuddy 用起来

从下载安装、主界面、第一个任务，到 Skill、专家团、连接器、外部 API 与自动化任务。

- [进入第一篇](/bluebook/%E7%AC%AC%E4%B8%80%E7%AF%87%20%E4%BD%BF%E7%94%A8%E6%89%8B%E5%86%8C%EF%BC%9A%E5%85%88%E6%8A%8A%20WorkBuddy%20%E7%94%A8%E8%B5%B7%E6%9D%A5/)

### 第二篇 · 案例篇：从一项任务到一支 AI 团队

办公三件套、整理桌面、远程控制、资讯整合、会议、投资分析、AI 视频、自媒体与 GEO 等真实案例。

- [进入第二篇](/bluebook/%E7%AC%AC%E4%BA%8C%E7%AF%87%20%E6%A1%88%E4%BE%8B%E7%AF%87%EF%BC%9A%E4%BB%8E%E4%B8%80%E9%A1%B9%E4%BB%BB%E5%8A%A1%E5%88%B0%E4%B8%80%E6%94%AF%20AI%20%E5%9B%A2%E9%98%9F/)

### 第三篇 · 进阶篇：把案例变成自己的工作系统

打造 Skill、多 Agent 系统设计、自动化工作流的可靠性。

- [进入第三篇](/bluebook/%E7%AC%AC%E4%B8%89%E7%AF%87%20%E8%BF%9B%E9%98%B6%E7%AF%87%EF%BC%9A%E6%8A%8A%E6%A1%88%E4%BE%8B%E5%8F%98%E6%88%90%E8%87%AA%E5%B7%B1%E7%9A%84%E5%B7%A5%E4%BD%9C%E7%B3%BB%E7%BB%9F/)

## 从哪里开始

- 完全新手：先读[阅读指南](/reading-guide)，从第一篇第 1 章开始。
- 带着任务来：直接跳到[第二篇案例篇](/bluebook/%E7%AC%AC%E4%BA%8C%E7%AF%87%20%E6%A1%88%E4%BE%8B%E7%AF%87%EF%BC%9A%E4%BB%8E%E4%B8%80%E9%A1%B9%E4%BB%BB%E5%8A%A1%E5%88%B0%E4%B8%80%E6%94%AF%20AI%20%E5%9B%A2%E9%98%9F/)，按问题找章节。
- 想把做法沉淀成系统：读第三篇与第四篇。
- 遇到具体工作场景不知道怎么解决：到[帮你解决](/help/)提交场景问卷。
